# Unified Inertial Encoder

Minimal Next.js and Tailwind CSS starter with an empty home page.

## Local development

```sh
npm ci
npm run dev
```

Open http://localhost:3000. Run `npm run lint` and `npm run build` to check the project.

## GitHub Pages

The workflow in `.github/workflows/deploy.yml` builds and deploys the static site on pushes to `main` or when run manually. In the repository's **Settings → Pages**, set **Build and deployment → Source** to **GitHub Actions**. The site is built for `https://unified-inertial-encoder.github.io/unified-inertial-encoder/`.
